# Página web de Ingeniería del Software 2

Sitio de la materia Ingeniería del Software 2 de la Facultad de Ingeniería de la Universidad de Buenos Aires.

## Desarrollo local

**Requisitos:** [Hugo](https://gohugo.io/getting-started/installing/), [Node.js](https://nodejs.org/) y npm.

```shell
git clone https://github.com/ingenieria-del-software-2/ingenieria-del-software-2.github.io
cd ingenieria-del-software-2.github.io
npm ci
git config core.hooksPath .githooks
npm run dev
```

El sitio queda disponible en `http://localhost:1313`.

> [!IMPORTANT]
> Configurá `core.hooksPath` una vez por clon. El hook `.githooks/pre-commit` se ejecuta cuando cambia `data/material.yaml`, regenera `data/autogenerated.json` y agrega el resultado al mismo commit. Esta generación se hace localmente porque las restricciones de red de GitHub Actions la vuelven inestable incluso al cambiar proxies o runtime (Go, Node o Python).

## Builds

| Objetivo | Comando |
| --- | --- |
| Producción local, equivalente al workflow principal | `npm run build` |
| Preview de un PR, equivalente a `pages-preview.yaml` | `PREVIEW_URL="https://<owner>.github.io/<repo>/pr-preview/pr-<numero>/" npm run build:prod:mr-preview` |

Ambos comandos requieren haber instalado antes las dependencias con `npm ci`. El patrón de `PREVIEW_URL` está definido en [`.github/workflows/pages-preview.yaml`](./.github/workflows/pages-preview.yaml).

## Mantenimiento por cuatrimestre

| Tarea | Archivo | Acción |
| --- | --- | --- |
| Actualizar el material | `data/material.yaml` | Agregar clases, videos, recursos y temas en su categoría. El hook actualiza `data/autogenerated.json`. |
| Actualizar el equipo docente | `data/team.yaml` | Agregar o modificar nombre, foto, correo y usuario de GitHub. |
| Actualizar la línea de tiempo | `data/fechas.yaml` | Cargar el calendario con fechas `YYYY-MM-DD`. `layouts/home.html` usa estas claves para los hitos y el marcador `HOY`. |

Ejemplo de `data/fechas.yaml`:

```yaml
inicio: "2026-03-09"
individual: "2026-03-19"
checkpoint1: "2026-04-13"
checkpoint2: "2026-05-11"
checkpoint3: "2026-06-04"
final: "2026-06-25"
```
