{{/*------------------------------------------------------------------------------ ytmeta.html — Hugo partial (intended to be used with partialCached) What it does: - Given a YouTube videoId, it resolves the metadata needed to render a media card: - title - thumb (thumbnail URL) - duration (formatted duration string) Why it looks weird: - Hugo can’t get duration from oEmbed. - YouTube oEmbed does NOT include duration (only title/thumbnail/etc). - So we intentionally do TWO requests: 1) oEmbed: https://www.youtube.com/oembed?... → title + thumbnail_url 2) youtubei/player: https://www.youtube.com/youtubei/v1/player?... → lengthSeconds How to use (IMPORTANT): - Call this partial with partialCached to avoid doing 2 HTTP requests per render: {{ $meta := partialCached "ytmeta.html" (dict "vidId" $vidId "title" $title "thumb" $thumb "duration" $duration) $vidId }} Cache key: $vidId (if you need to vary by locale/region, use a composite key). Fallback behavior: - If oEmbed fails, we keep any title/thumb coming from frontmatter. - If thumb is still empty, we fall back to i.ytimg.com/vi//hqdefault.jpg - If youtubei/player fails, duration stays empty (caller can hide the badge). Maintenance notes: - youtubei/player uses YouTube’s public “WEB” key/endpoint behavior and may break if YouTube changes it. - Headers (Origin/Referer/User-Agent) are set so YouTube responds like it would to a browser. - Don’t “optimize” this into one call: there’s no simple unauthenticated endpoint that returns oEmbed + duration reliably in one shot. ------------------------------------------------------------------------------*/}} {{- $vidId := .vidId -}} {{- $m := dict "title" .title "thumb" .thumb "duration" .duration -}} {{- $oembedUrl := printf "https://www.youtube.com/oembed?url=https://www.youtube.com/watch?v=%s&format=json" $vidId -}} {{- with try (resources.GetRemote $oembedUrl) -}} {{- with .Err -}} {{- warnf "OEmbed failed for %s: %s" $vidId . -}} {{- else with .Value -}} {{- $d := .Content | transform.Unmarshal -}} {{- $m = merge $m (dict "title" (default $d.title $m.title) "thumb" (default $d.thumbnail_url $m.thumb)) -}} {{- end -}} {{- end -}} {{- if not $m.duration -}} {{- $durationStatus := "" -}} {{- $durationReason := "" -}} {{- $durationDetail := "" -}} {{- $body := dict "context" (dict "client" (dict "hl" "en" "clientName" "WEB" "clientVersion" "2.20210622.10.00")) "videoId" $vidId -}} {{- $opt := dict "method" "POST" "body" (jsonify $body) -}} {{- $api := "https://www.youtube.com/youtubei/v1/player?key=AIzaSyAO_FJ2SlqU8Q4STEHLGCilw_Y9_11qcW8" -}} {{- with try (resources.GetRemote $api $opt) -}} {{- with .Err -}} {{- $durationDetail = printf "error en youtubei/player: %s" . -}} {{- else with .Value -}} {{- $data := .Content | transform.Unmarshal -}} {{- with $data.playabilityStatus.status -}} {{- $durationStatus = . -}} {{- end -}} {{- with $data.playabilityStatus.reason -}} {{- $durationReason = . -}} {{- end -}} {{- with (index $data "videoDetails" "lengthSeconds") -}} {{- $seconds := . | int -}} {{- if gt $seconds 0 -}} {{- $t := $seconds | time.AsTime -}} {{- $dur := $t.Format "4:05" -}} {{- if ge $seconds 3600 -}} {{- $dur = $t.Format "15:04:05" | replaceRE "^0" "" -}} {{- end -}} {{- $m = merge $m (dict "duration" $dur) -}} {{- else -}} {{- $durationDetail = printf "lengthSeconds inválido (%v)" . -}} {{- end -}} {{- else -}} {{- $durationDetail = "lengthSeconds ausente en videoDetails" -}} {{- end -}} {{- else -}} {{- $durationDetail = "youtubei/player sin respuesta y sin error explícito" -}} {{- end -}} {{- end -}} {{- if not $m.duration -}} {{- $durationDetail = default "sin detalle adicional" $durationDetail -}} {{- warnf "No se pudo obtener duration de YouTube para %q: status=%q reason=%q detail=%q" $vidId $durationStatus $durationReason $durationDetail -}} {{- end -}} {{- end -}} {{- $m = merge $m (dict "thumb" (default (printf "https://i.ytimg.com/vi/%s/hqdefault.jpg" $vidId) $m.thumb)) -}} {{- return $m -}}
